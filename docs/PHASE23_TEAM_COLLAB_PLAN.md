## 二、业界对标分析

### 2.1 自托管项目管理工具对比

| 工具 | 用户模型 | 权限粒度 | 部署 | 强项 | PromptKit可借鉴 |
|------|---------|---------|------|------|----------------|
| **Plane.so** | Workspace→Project→Member | Admin/Member/Commenter/Guest 4级 | Docker一键 | 现代UI+AI Agents | 工作空间概念、AI代理分配任务 |
| **OpenProject** | 项目组合→项目→成员 | 自定义角色+权限矩阵 | 包管理器/RPM | Gantt+时间追踪+预算 | 自定义角色矩阵、项目组合视图 |
| **Taiga** | 项目→成员 | Owner/Member/Viewer 3级 | Docker | Scrum/Kanban原生 | 简洁角色模型、Sprint周期 |
| **Focalboard** | 工作区→看板 | Admin/Editor/Commenter/Viewer | 单二进制 | Notion替代+多视图 | 板块/表格/画廊三视图切换 |
| **Wekan** | 看板→成员 | Admin/Normal/CommentOnly | Snap/Meteor | Trello替代+检查清单 | 卡片检查清单、标签着色 |

### 2.2 AI/ComfyUI多用户方案对比

| 方案 | 用户管理 | 权限模型 | 部署 | PromptKit可借鉴 |
|------|---------|---------|------|----------------|
| **ComfyUI --multi-user** | 内置用户注册 | admin/user 2级 | 一行参数 | LAN 多用户开箱即用 |
| **ComfyUI-Nexus** | 服务端唯一安装 | Admin/Editor/Viewer + 队列权限 | 自定义节点 | 编辑器/查看者分离、队列权限控制 |
| **ComfyICU Teams** | 项目+角色权限 | 项目管理+成本追踪 | SaaS | 用量/成本追踪、客户端隔离 |

### 2.3 核心共性模式提炼

```
所有成功方案的三要素：
┌─────────────────────────────────────────────┐
│ 1. 工作空间(Workspace) → 容器               │
│    └─ PromptKit映射: master_project = 工作空间 │
│                                               │
│ 2. 成员(Member) → 角色 → 权限矩阵              │
│    └─ 最小值: Admin/Editor/Viewer 3角色        │
│    └─ 成熟值: 自定义角色 + 细粒度权限           │
│                                               │
│ 3. 数据隔离 → 3级                             │
│    └─ 全局共享 / 工作空间共享 / 个人私有        │
└─────────────────────────────────────────────┘
```

### PromptKit 的差异化优势

1. **AIGC 原生**: 不是通用PM工具，是专为AIGC影片制作设计的全流程平台
2. **12角色精准匹配**: 比通用3-4角色模式更贴合影视制作团队结构
3. **提示词继承链**: 全局→段落→镜头三层叠加，业界独有的AIGC风格一致性方案
4. **局域网优先+远程预埋**: 数据完全本地化，无云依赖
5. **零外部依赖**: Python标准库 + SQLite + 单文件部署
6. **已集成 AI 引擎**: 16个Ollama模型 + ComfyUI自动发现
