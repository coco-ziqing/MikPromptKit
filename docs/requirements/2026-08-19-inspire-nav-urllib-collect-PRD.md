## 1. 文档概述

### 1.1 产品目标
搭建「灵感站点导航 + 浏览器URL抓取 + 应用内URL收藏管理」完整前置搜集链路，解决用户灵感素材快速浏览、多站点多标签批量归集、统一收藏初筛的能力，为下游批量采集、归档、分镜、投稿提供标准化原始URL素材池。

### 1.2 业务核心逻辑
- 浏览外放：所有灵感网页浏览全部在系统外部浏览器完成，支持多标签自由浏览
- 抓取轻量化：浏览器仅负责回传URL，所有解析、抓取、筛选、清洗、管理全部在应用内完成
- 搜集轻量化：前端搜集阶段不做精细分类、不精细打标、不素材下载，仅做灵感标记
- 后置处理：URL去重、清洗、分层、精细归档全部后置到采集环节

### 1.3 整体业务链路
灵感站点导航页 → 唤起外部浏览器打开灵感站点 → 用户多标签浏览筛选灵感页面 → 单条/批量/手动三种方式获取页面URL → 应用后台抓取基础信息 → 存入应用内URL收藏库 → 应用内批量筛选清理 → 生成批量采集任务 → 移交采集归档模块

## 2. 功能模块总览
1. 灵感站点导航页（应用内入口、预制站点+用户自定义站点）
2. 浏览器扩展抓取能力（单页抓取、多标签批量抓取、URL回传）
3. 应用内URL收藏库（信息预览、批量筛选、URL清理、任务产出）

## 3. 模块详细需求

### 3.1 灵感站点导航页（应用内首页级入口）
#### 3.1.1 功能说明
统一灵感素材站点入口，支持系统预制站点与用户自定义站点，一键唤起外部浏览器打开，作为全链路搜集起点。

#### 3.1.2 页面功能明细
- 系统预制灵感站点：后台可配置分组（提示词站点、灵感图库、设计参考、素材榜单等），默认展示，不可删除
- 用户自定义站点：用户可自主新增、编辑、删除、个人收藏站点
  - 新增字段：站点名称、站点URL、备注说明
  - 支持个人站点分组管理
- 跳转规则：点击任意站点，唤起系统默认外部浏览器新开标签打开，不内嵌iframe，不限制浏览操作
- 页面提示文案：引导用户「浏览器浏览灵感页面，可使用插件一键抓取页面地址回传至收藏库」

#### 3.1.3 业务规则
- 导航页仅做跳转入口，不加载素材预览、不做内容解析
- 不限制用户浏览器新开标签数量，完全自由浏览

### 3.2 浏览器扩展能力（核心桥梁）
#### 3.2.1 功能说明
用户在外部浏览器浏览任意灵感页面，提供三种URL归集方式，将浏览器标签地址回传至应用后台，不读取隐私数据，仅获取公开页面信息。

#### 3.2.2 三种抓取模式（全部支持）
1. 单页一键获取（常用）：当前激活页面，点击扩展「加入灵感收藏库」→ 自动抓取当前标签URL，回传应用后台
2. 多标签批量一键获取（高效批量）：点击扩展「批量抓取全部标签」→ 读取当前浏览器全部打开标签URL → 回传应用端，弹出预览列表，用户手动勾选确认后入库（防止无效标签误录入）
3. 手动粘贴兜底模式：应用内提供URL输入框，用户手动复制粘贴链接提交入库

#### 3.2.3 权限与安全约束
- 仅读取标签URL、页面公开源码，不读取Cookie、密码、表单隐私数据
- 仅对公开网页生效，受限/加密页面禁止抓取

### 3.3 应用后台信息抓取能力
#### 3.3.1 触发条件
浏览器回传URL / 用户手动提交URL后，后台异步自动抓取页面公开基础信息，无需用户操作。

#### 3.3.2 抓取字段（用于收藏库预览、人工初筛判断）
- 原始URL（完整保留，不清洗、不修改）
- 页面标题 Title
- 页面描述 Meta-Description
- 页面正文核心文本（优先抓取提示词、文案内容）
- 页面首图/缩略图
- 来源站点名称、域名
- 入库时间、操作人
- 抓取状态：抓取成功 / 抓取失败

#### 3.3.3 业务规则
- 抓取失败链接保留原始URL，标记状态，不自动删除
- 搜集阶段不做URL去重、不清洗参数、不短链还原
- 不下载完整素材，仅抓取预览文本与缩略图

### 3.4 URL收藏库（应用内核心管理页）
#### 3.4.1 功能定位
所有浏览器归集的URL统一汇总页面，是搜集阶段唯一初筛、批量清理工作台，完成素材筛选分层，输出批量采集任务。

#### 3.4.2 页面列表字段
勾选框、缩略图、页面标题、文本摘要/提示词预览、来源站点、原始URL、入库时间、抓取状态、操作按钮

#### 3.4.3 单条操作
- 打开原网页
- 复制URL
- 移除当前条目
- 标记状态：待处理 / 待采集 / 备用 / 废弃

#### 3.4.4 批量操作能力（核心开发功能）
- 批量勾选、批量删除
- 批量状态变更：批量设为待采集/备用/废弃
- 批量URL清洗（应用内完成）
  - URL基础去重（域名+页面指纹）
  - 清理追踪参数、多余后缀参数
  - 短链接还原标准链接
  - 过滤抓取失败、失效无效链接

#### 3.4.5 数据池分层管理
- 待处理池：刚从浏览器回传的原始URL，未筛选、未清洗
- 待采集池：人工确认有效、清洗完成，可直接生成采集任务
- 备用池：有灵感价值、暂不采集，延后复用
- 废弃池：无效、违规、低质链接，留存记录可复盘

#### 3.4.6 下游输出能力
用户筛选完成后，勾选待采集数据，一键生成批量采集任务，同步数据至「采集归档模块」，携带完整元信息（URL、标题、提示词文本、缩略图、来源）。

## 4. 完整用户操作流程（标准流程）
1. 进入【灵感站点导航页】，选择预制/自定义灵感站点
2. 点击站点，唤起外部浏览器打开网页
3. 用户自由新开多标签，浏览提示词/图片灵感页面，人工粗略筛选有效素材页
4. 选择抓取方式：单页一键收藏 / 批量抓取全部标签 / 手动粘贴URL
5. URL回传应用后台，后台异步抓取页面基础预览信息
6. 数据自动存入【URL收藏库-待处理池】
7. 用户在收藏库完成：人工初筛、批量URL清洗、状态分层
8. 确认有效素材，生成批量采集任务，移交下游链路

## 5. 核心业务边界（开发必须严格遵守）
- ✅ 浏览器：仅浏览、仅回传URL，不做任何数据处理、不做筛选清洗
- ✅ 搜集阶段：只做灵感浏览、URL收藏标记、系统自动粗抓取
- ✅ 应用内：完成所有筛选、清洗、分层、任务生成
- ❌ 禁止搜集阶段精细分组、手动打细标签
- ❌ 禁止浏览器端自动批量入库（必须用户确认）
- ❌ 禁止搜集阶段修改、清洗原始URL（保留溯源原始数据）

## 6. 异常处理规则
- URL失效/404：标记「抓取失败」，保留链接，不自动删除
- 页面加密/禁止爬取：标记抓取异常，人工复核
- 重复URL入库：允许重复入库，统一在收藏库批量去重
- 批量抓取空标签：提示「无有效浏览器标签」，不生成空数据

## 7. 对接下游模块
本模块输出：批量标准化URL素材池+基础元数据
下游承接：采集归档 → 素材挑选 → 分镜制作 → 视频审核 → 填表投稿
