## 四、经验教训

1. **`prompt_library` 是 VIEW 不是表**：`PRAGMA table_info` 看得到列就误当表写，实际 `INSERT INTO prompt_library` 必 500。查 `sqlite_master.type` 确认表/视图是写库第一前提（教训：任何"看起来是表"的对象先查 type）。
2. **自定义分组功能"从未真正工作过"**：createCustomLib 一直报「创建未完成」—— 前端把 500 吞成模糊提示。修复真实表写入后功能才真正可用。模糊错误提示会掩盖系统性 bug。
3. **测试真实生成会消耗额度**：视频测试触发了真实 CLI 提交（即梦并发限制救了一次）。开发验证应先测参数校验/空项目路径，真实生成需用户确认。
4. **emoji 锚点匹配失败**：`🛡` 与 `🧠` 视觉相近，patch 锚点必须从 read 工具原文复制而非凭记忆。
