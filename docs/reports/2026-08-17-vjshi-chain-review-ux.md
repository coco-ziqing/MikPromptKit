# 光厂投稿素材生产投稿流程 — 逐环节功能梳理 + 全链路体验升级

- **梳理日期**：2026-08-17
- **关联版本**：主项目 v5.40.1（全链路功能已齐）+ 需求分析模块 v1.3
- **梳理方式**：逐文件代码走查（后端 vjshi_upload.py 66KB / video_quality / word_quality / production_funnel + 前端 vjshi_upload_ui.js / card_gen_ui.js / app_core.js / app_collections_batch.js）+ 运行态 API 核对
- **结论**：11 环节功能全部在库，但**跨环节体验存在 10 处缺口**，本次按「体验优化」升级

---

## 一、逐环节功能梳理（现状核对）

### 环节① 合规题材数据人工采集研判 — ✅ 完整
- 模块：需求分析（ted_module :8085，独立库 ted_analysis.db）
- 能力：机会榜/热搜榜/关键词周报/销售记录四表型上传 → 四池划分 → 研判工作台 → 规划书（含合规风控章节）→ 版本对比
- 体验缺口：无（独立模块自洽）

### 环节② 灵感多途径筛选 — ✅ 完整
- 即梦灵感搜索（滚动采集 ≤8 轮、预览 ≤40、单次导入 ≤10）+ 历史资产双通道导入（CLI+网页，2306 条真实资产）
- 体验缺口：无

### 环节③ 人工词卡归档 — ✅ 完整
- 灵感导入并存词卡 / 手动新建 / 分组归档 / AI 标注分类
- 体验缺口：无

### 环节④ 词卡提示词质检评分 — ✅ 完整（v5.39.0）
- word_quality.py 四维规则评分（完整性30/合规25/生产适配20/文本质量15 + AI 一致性10%），独立表 word_card_quality
- 前端：批量弹窗「质检评分」按钮（app_collections_batch.js _batchQualityCheck）评分面板
- 体验缺口：无

### 环节⑤ 人工预览图验证筛选 — ✅ 完整
- 词库媒体缩略图 / 查看原图 / 左右切换 / 档位切换
- 体验缺口：无

### 环节⑥ seedance 视频批量生成 — ✅ 完整
- batch-precheck 预检（no_content/file_missing/prompt_long/manual/ai_other 风险分类）→ 批量入队 ≤20 → 8s 轮询 → 完成通知（toast+标题闪烁+Web Audio）
- 体验缺口：**生成完成 → 投稿之间无批量入口**（只能逐条点「📤 上传」）

### 环节⑦ 本地视频质检 — ✅ 完整（v5.40.0）
- video_quality.py ffprobe 解析（时长/分辨率/编码/fps/大小）+ 规则校验（≥5s/≤15min/≥720p/H.264/≤2GB），ffprobe 缺失降级 ffmpeg -i
- 投稿弹窗自动质检 ✅/⚠️/❌ + 不通过阻止提交（worker 内同样拦截 fail_category=video_invalid）
- 体验缺口：质检结果不可手动重跑；质检通过信息不落库展示

### 环节⑧ 人工触发合规自动填表投稿 — ✅ 完整（已加固）
- vjshi_upload.py：Playwright 持久化 profile + 串行 worker + 总超时 900s + 看门狗 20min + 连续失败熔断 + 单时6/日30/批20 + 45s±15s 节奏
- 弹窗：标题/关键词/简介/AI 优化简介/分类/价格/AI 标注 + 登录引导
- 体验缺口（本次重点）：
  1. **🐛 登录提示区 `#vjLoginHint` 从未渲染**（JS 查询但 HTML 未生成该 div → 登录引导永远不显示）
  2. 标题无 10-30 字计数/校验；关键词标签写「逗号分隔」实际平台要求空格分隔 ≥5 个（误导）
  3. 简介无字数计数（平台 ≤300 字）
  4. 质检结果无法手动重跑
  5. 视频预览仅 hover 播放，无点击播放控件
  6. **批量入队无 UI**（后端 /api/vjshi/batch 存在但前端从未调用）
  7. 入队后无法编辑任务字段（标题/关键词/简介/价格）

### 环节⑨ 批量投稿审核跟踪 — ✅ 功能在 / ⚠️ UI 不全
- 后端：review_status/reject_reason 列 + PUT /tasks/{tid}/review + POST /review-batch
- 前端：单条三按钮标记 + 审核筛选下拉 + 徽章
- 体验缺口：
  1. **批量标记无 UI**（/review-batch 后端存在但前端不调用，只能逐条点）
  2. 无「待审核」（submitted 且未标记）筛选与计数
  3. 被拒原因仅自由文本，无常见原因预置
  4. 已提交任务无审核流程指示（待审核 → 审核中 → 上架/被拒）

### 环节⑩ 上线精筛上架台账 — ✅ 功能在 / ⚠️ 体验糙
- vjshi_online_catalog 表 + CRUD API + 「从已上架任务加入」
- 体验缺口：
  1. 表现录入用**两个连续 prompt() 弹窗**（销量/收益），无法改链接，体验糙
  2. 无筛选（在架/已剔除）与汇总统计
  3. 从已上架任务加入无去重提示、逐条 setTimeout 串行

### 环节⑪ 销售数据回流 — ✅ 完整
- sales_record 表型自动识别 → 合并分析注入 merged_orders → 题材池重排（verified_orders 徽章）
- 体验缺口：无

### 横向看板：生产链路漏斗 — ✅ 功能在 / ⚠️ 无联动
- /api/production/funnel 聚合 5 级（题材池→词卡→生成→投稿→上架→销售）
- 体验缺口：**各级无跳转按钮**（看了数字无法直达对应面板）

## 三、升级改造清单（v5.41.0 体验优化批次）

### 后端（vjshi_upload.py）
- B1 `PUT /api/vjshi/tasks/{tid}`：编辑 queued/fail 任务字段（title/keywords/description/category/price/is_ai；进行中/已提交拒绝）
- B2 `GET /api/vjshi/candidates`：可投稿候选视频（card_gen_tasks done + video + 文件存在 + 未投过），支持 keyword 过滤
- B3 `/api/vjshi/tasks` 列表响应补 fail_category 中文化映射与状态统计（待审核数等）

### 前端（vjshi_upload_ui.js，主战场）
- F1 投稿弹窗：渲染登录状态区（修复 bug）+ 标题 10-30 字计数校验 + 关键词标签修正（空格分隔≥5）+ 简介 ≤300 计数 + 「🔄 重新质检」+ 视频点击播放
- F2 队列面板：状态筛选 tabs + 失败分类徽章 + progress_note + ETA + 待审核计数 + 审核流程指示
- F3 批量审核：任务多选 checkbox + 底部操作条（批量标记 审核中/已上架/被拒）
- F4 批量投稿：面板「📦 批量投稿」→ 候选列表（带质检状态）→ 勾选批量入队
- F5 任务编辑：queued/fail 任务「✏️ 编辑」弹窗（PUT）
- F6 上架台账：表现/链接内联编辑弹窗 + 筛选（在架/剔除）+ 汇总行 + 加入去重提示
- F7 后台完成提醒：有活跃任务时 30s 轻轮询，提交成功/失败 toast（对齐 card_gen 通知模式）

### 看板（app_core.js）
- F8 漏斗每级加跳转按钮：题材池→需求分析、词卡→词库、生成→生成任务面板、投稿→光厂队列、上架→上架台账
