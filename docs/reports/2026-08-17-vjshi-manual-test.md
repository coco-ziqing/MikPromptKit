## 模块 A：投稿弹窗（单条）

> 入口：**生成任务面板**（词库「🚀 生成」→ 顶部任务队列）→ 任意成功视频产物行的「📤 上传」；或 **📦 批量投稿** 面板里的「📤 单条」

- [ ] **A1 登录提示区**（本轮修复的 bug）
  - 操作：打开投稿弹窗
  - 预期：弹窗顶部出现状态框 —— 光厂未登录时显示「⚠️ 第一步：请先登录光厂账户 + 🔑 打开登录窗口」按钮；已登录显示「✅ 光厂账户已登录」
  - ❌ 若此框不显示 = 修复未生效

- [ ] **A2 视频质检自动运行 + 重新质检**
  - 操作：打开弹窗观察「🔍 视频质检」区
  - 预期：约 2-5 秒后显示「通过/警告/不通过」+ 时长/分辨率/编码/大小 + 「🔄 重新质检」按钮
  - 操作：点「🔄 重新质检」→ 预期重新出现「质检中...」后再次出结果

- [ ] **A3 视频点击播放/暂停**
  - 操作：点弹窗内视频预览
  - 预期：点击开始播放（出现高亮描边），再点暂停

- [ ] **A4 标题计数与校验**
  - 操作：清空标题 → 输入短标题（如「测试」）→ 观察右侧计数
  - 预期：计数实时变化（n/30）；不足 10 字时数字变红
  - 操作：点「📤 确认投稿」
  - 预期：toast 提示「标题建议 ≥10 字」并**阻止提交**
  - 操作：输入超 30 字标题 → 确认投稿 → 预期提示「标题超 30 字」并阻止

- [ ] **A5 关键词计数与校验**
  - 操作：关键词框输入「蓝色 背景 商务」（3 个词）
  - 预期：右侧显示「3 词」变红；确认投稿 → 提示「关键词需 ≥5 个」并阻止
  - 操作：补齐 5 个词（空格分隔）→ 计数变正常色

- [ ] **A6 简介计数**
  - 操作：输入超 300 字简介
  - 预期：计数变红；确认投稿 → 提示「简介超 300 字」并阻止

- [ ] **A7 质检拦截（用不合格视频）**
  - 操作：📦 批量投稿面板 → 找标题含 4.1s 的候选（「cg_1d89...」或「cg_66ab...」）→ 点「📤 单条」
  - 预期：质检区显示「❌ 不通过（时长 4.1s 不足 5s）」；点确认投稿 → toast「视频质检不通过」**阻止提交**

- [ ] **A8 取消**：点「取消」→ 弹窗关闭，**不产生**队列任务

## 模块 B：上传队列面板

> 入口：生成任务面板顶部「📤 光厂队列」；或面板内任何操作后自动刷新

- [ ] **B1 状态筛选 tabs**
  - 操作：点「⏳ 排队」「📤 执行中」「✅ 已提交」「❌ 失败」「🕐 待审核」
  - 预期：列表按状态过滤；「待审核」tab 显示计数（测试数据有 1 条，应显示 ≥1）；tab 切换**不叠层**（只更新内容，不新增弹窗）
  - 再点「全部」→ 恢复全量（顶部计数 = 各状态之和）

- [ ] **B2 失败分类徽章**
  - 操作：切到「❌ 失败」tab
  - 预期：`[测试] 超时失败任务` 显示红色徽章「任务超时（可重试）」

- [ ] **B3 排队 ETA**
  - 操作：切到「⏳ 排队」tab
  - 预期：顶部显示「排队预计 ~2 分钟」（2 条排队 × 45s）

- [ ] **B4 审核流程指示**
  - 操作：查看「[测试] 待审核任务」与「[测试] 已上架任务」
  - 预期：已提交任务显示流程条：`已提交 → 审核中 → 待定/已上架`；已上架任务流程条终点为绿色「已上架」

- [ ] **B5 单条审核标记**
  - 操作：对「[测试] 待审核任务」点「⏳审核中」→ 刷新
  - 预期：徽章变「⏳ 审核中」+ 流程条推进
  - 操作：点「✅上架」→ 徽章变「✅ 已上架」
  - 操作：点「❌被拒」→ 弹 prompt 录入原因 → 徽章变「❌ 被拒」+ 显示原因

- [ ] **B6 多选批量审核**（本轮新增 UI）
  - 操作：勾选 2 条以上已提交任务的 checkbox
  - 预期：出现紫色操作条「已选 N 条 + 批量:审核中/已上架/被拒 + 取消选择」
  - 操作：点「✅ 批量:已上架」→ toast「已批量标记 N 条」→ 全部变已上架
  - 操作：再勾选 → 点「❌ 批量:被拒」→ prompt 填原因 → 全部变被拒 + 原因
  - 预期：操作条随选择数实时更新；点「取消选择」清空

- [ ] **B7 编辑任务 ✏️**（本轮新增）
  - 操作：排队/失败任务行点「✏️」→ 改标题/价格 → 保存
  - 预期：toast「✅ 已保存」，列表标题/价格更新
  - 操作：对「已提交」任务（如有）点 ✏️ → 预期被拒提示「任务已提交，请通过审核标记更新状态」（后端 400）
  - ⚠️ 编辑排队任务不影响其状态（仍排队，勿点恢复）

- [ ] **B8 面板防叠层**
  - 操作：连续点 3 次「🔄 刷新」、切换几次 tab
  - 预期：始终只有 1 个队列面板（不出现多个重叠弹窗）

- [ ] **B9 后台完成提醒**（可选，需真实执行）
  - 原理：面板/网页开着时，有「排队/执行中」任务 → 每 30s 后台探测；任务从执行中变已提交/失败 → toast 提醒
  - 操作：批量入队 1 条**合格**视频（见模块 C）→ 关闭面板 → 等 worker 执行（约 1-3 分钟，会真实上传！）
  - 预期：弹出「📤 光厂投稿成功：xxx」toast
  - ⚠️ 此测试会真实投稿一条到光厂，仅在你愿意时执行
