# AIGC 影片制作全流程功能模块分析 — Phase22 架构补全
# 日期: 2026-07-11

## 一、完整 AIGC 影片制作流水线（7阶段）

```
                    ┌─────────────────────────────────────────────┐
                    │         AIGC 影片制作全生命周期              │
                    └─────────────────────────────────────────────┘

[前期策划] ──→ [预生产] ──→ [资产准备] ──→ [分镜生产] ──→ [后期合成] ──→ [审核交付] ──→ [复盘归档]
  P0             P1            P2            P3            P4           P5            P6
```

## 二、7阶段功能模块清单

### P0 — 🧠 前期策划（Ideation）

| 模块 | 功能 | 依赖 |
|------|------|------|
| 📝 创意简报 | 影片类型/目标受众/核心信息/参考链接 | 纯文本 |
| 🎯 风格定位 | 视觉风格板(moodboard)/色调方案/参考影片 | 图片上传 |
| 📐 技术规格 | 分辨率/帧率/时长/画幅/输出格式 | 表单 |
| 💰 资源估算 | Token预算/API调用/预计耗时 | AI预估 |
| 📊 竞品分析 | 同类作品参考/差异化定位 | 纯文本+图片 |

---

### P1 — 📝 预生产（Pre-production）

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|
| ✍️ **剧本编辑器** | 分幕/分场/对白/旁白/动作描述 | 富文本编辑器 | 可集成 word_card 提示词库 |
| 🔄 **剧本→分镜自动拆解** | AI分析剧本自动生成分镜脚本 | LLM | 调用 Ollama（已有16模型池） |
| 🎭 **角色档案** | 姓名/外观/性格/背景故事/表情集 | 图片+Prompt | 关联 ComfyUI 角色 LoRA |
| 🌍 **场景档案** | 场景描述/氛围/时间/光线/色调/参考图 | 图片+Prompt | 关联 ComfyUI 场景图生成 |
| 🎞️ **分镜脚本表** | 镜头号/景别/构图/动作描述/持续时间/运镜 | 表格视图 | **→ 自动生成 seedance 子项目** |
| 📋 **词卡模板绑定** | 每个镜头绑定提示词模板（word_card） | 词卡库 | 关联 word_card 表（694条） |
| 🔗 **提示词继承链** | 全局风格词卡 → 段落词卡 → 镜头词卡（多层叠加） | 提示词合并引擎 | 新增 |

---

### P2 — 🎨 资产准备（Asset Preparation）

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|
| 👤 **角色生成** | AI文生图生成角色立绘/表情包 | ComfyUI/Stable Diffusion | 集成 ComfyUI 自检（已有） |
| 🌍 **场景生成** | AI生成场景概念图/氛围参考 | ComfyUI | 同上 |
| 🎨 **风格一致性** | 跨角色/场景风格强制统一（LoRA+Prompt注入） | ComfyUI+LLM | 新增 |
| 📚 **资产库** | 角色/场景/道具/贴图 分类存储+标签检索 | 文件管理 | 可复用 library_assets（233条） |
| 🔖 **资产版本** | 每资产多版本（V1/V2/V3）+ 差异对比 | 版本控制 | 类似 prompt_versions |
| 🏷 **资产-镜头映射** | 标记每个资产被哪些镜头使用 | 关联表 | 新增 |
| 🎵 **音频资源** | BGM/音效/配音 素材管理 | 文件上传 | 已有 seedance BGM/SFX 字段 |

---

### P3 — 🎬 分镜生产（Shot Production）← 核心产出阶段

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|
| 🖼 **提示词生成** | 角色+场景+词卡模板 → AI融合生成最终提示词 | LLM | 集成 Ollama |
| 🔁 **批量生成** | 一键批量提交所有镜头到 ComfyUI/Seedance | API队列 | 新增（关键） |
| 📊 **生成面板** | 实时查看生成进度/队列/成功/失败/重试 | WebSocket | 新增 |
| 🔍 **逐镜头预览** | 生成结果即时查看/对比/选择最优 | 图片预览 | 已有缩略图系统 |
| ✏️ **单镜头微调** | 对不满意镜头手动调 Prompt 重新生成 | 提示词编辑器 | 已有 word_editor |
| 📋 **批量审核** | 逐镜头标记 ✅通过/❌重做/💬备注 | 审核面板 | 已有 project_tasks 可扩展 |
| 📦 **镜头打包** | 选中的镜头组导出为素材包 | 导出 | 已有导出功能 |
| 🎞️ **片段预览** | 静态镜头序列快速轮播预览（幻灯片模式） | 前端 | 新增 |

---

### P4 — ✂️ 后期合成（Post-production）

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|
| 🎬 **视频生成** | 图生视频（调用 Seedance/Runway/Kling） | Seedance API | 已有 seedance 集成 |
| 🎞️ **时间轴组装** | 拖拽镜头到时间轴/调整持续时长/转场 | 前端时间轴组件 | 可扩展 seedance 分镜组装器 |
| 🔊 **音频配乐** | 为每个镜头/段落绑定 BGM/音效/旁白 | 音频选择器 | 已有 BGM/SFX/旁白库 |
| 🌈 **色彩统一** | 批量应用色彩 LUT/滤镜 | 图像处理 | 新增 |
| 🎬 **字幕叠加** | 基于剧本自动生成字幕时间轴 | SRT/ASS | 新增 |
| 📦 **成片渲染** | 多格式导出（MP4/GIF/序列帧） | FFmpeg | 已有 ffmpeg 自检 |
| 🔄 **版本对比** | 导出版本 A/B 并列对比 | 前端 | 新增 |

### P5 — ✅ 审核交付（Review & Delivery）

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|
| 🔍 **逐级审核** | 分镜师→导演→制片人 三级审核流 | 角色权限 | 已有12角色体系 |
| 💬 **标注反馈** | 在镜头帧上画框标注+文字评论 | Canvas标注 | 新增 |
| 📊 **审核仪表盘** | 审核进度/通过率/重做率 可视化 | 图表 | 已有仪表盘框架 |
| 📄 **项目报告** | 自动生成制作报告（镜头数/成功率/耗时/Token消耗） | 数据聚合 | 新增 |
| 📦 **交付包** | 一键导出：成片+源文件+提示词+报告 .zip | 打包 | 已有导出功能 |
| 🔗 **分享链接** | 生成局域网可访问的审阅链接（无需登录） | 临时token | 新增 |

### P6 — 📊 复盘归档（Retrospective）

| 模块 | 功能 | 依赖 | 与现有系统的关系 |
|------|------|------|----------------|

## 七、数据模型最终态

```
master_project                                    ← 总项目
├── master_sub_project (1:N)                      ← 分镜段落
│   ├── seedance user_project (1:1)               ← 现有分镜项目
│   └── user_project_scene (1:N)                  ← 镜头
├── master_asset (1:N)                            ← 资产池
│   ├── asset_type=script       → 剧本
│   ├── asset_type=character    → 角色（可关联 ComfyUI 生成结果）
│   ├── asset_type=scene        → 场景（可关联场景概念图）
│   ├── asset_type=prompt_template → 词卡模板（关联 word_card）
│   ├── asset_type=ref_image    → 参考图
│   ├── asset_type=bgm          → 背景音乐
│   └── asset_type=sfx          → 音效
├── project_columns (1:N)        ← 看板列（扩展 master_project_id）
├── project_tasks (1:N)          ← 任务（扩展 master_project_id）
│   ├── phase=P0~P6              ← 新增阶段字段
│   └── task_type=shot/ap/asset  ← 新增任务类型
└── project_milestones (1:N)     ← 里程碑
```
