# 光厂（VJ师网）AI 视频素材批量上传自动化 — 深度分析与开发规划 v2

> 版本：v5.38.0 规划（v2，含深度方案对比）| 日期：2026-08-14 | 状态：待评审

---

## 一、需求总览

依托本地 WebUI 词卡 AI 视频生成能力（v5.37.0 已就绪：`data/card_gen/videos/` 产物 + 词卡生成历史），为光厂（vjshi.com）供稿适配：**将生成的视频素材批量上传 + 自动填写素材信息**（标题/关键词/简介/分类/价格），浏览器自动化填表上传。

## 二、光厂平台调研（已核实）

### 2.1 上传链路
| 项 | 结论 |
|----|------|
| 平台 | 视觉中国旗下「光厂 VJ师网」，正版视频素材交易平台 |
| 上传入口 | `vjshi.com/upload-nav`（三步极速投稿，分成 70-75%） |
| 流程 | ①选素材上传（视频文件）→ ②**完善素材信息**（标题/简介/关键词/分类/价格等）→ ③提交审核 |
| 审核 | 约 1 个工作日；**标题/关键词填写不规范会被拒**；信息含广告/联系方式会被拒 |
| 素材要求 | 本人原创、时长 ≤15 分钟、单镜头优先；**AI 作品可上架**（有「AI作品上架规则」） |
| 上传额度 | 政策协议含「素材上传额度」（账号维度限制） |
| API | **无公开 API**，上传/填表只能走网页 |

### 2.2 现成工具结论
**网络搜索无第三方批量上传辅助工具**（均为官方投稿引导/第三方教程），需自研浏览器自动化。

## 三、实现方案对比（深度分析）

### 方案 A：Playwright 全自动浏览器自动化（⭐ 推荐主方案）
```
本地服务 → Playwright（持久化 profile data/vjshi_profile/）→ 人工首次登录（密码/扫码）
 → worker 串行：打开上传页 → input[type=file] 选视频 → 等上传完成
 → 自动跳转「完善素材信息」→ 填标题/关键词/简介/分类/价格 → 提交
```
- **优点**：全自动、可批量、可调度、失败可重试；复用即梦网页通道经验（独立 profile + CDP）
- **缺点**：表单选择器依赖页面结构（需实测抓取一次固化）；平台风控需模拟节奏
- **适用**：日常批量投稿主力

### 方案 B：Chrome 扩展注入自动填表（辅助增强）
```
本地服务生成「上传清单」（视频+元数据 JSON）→ Chrome 扩展注入光厂上传页自动填表
```
- **优点**：跑在真实浏览器（登录态天然、反检测低）；无需 CDP
- **缺点**：需手动安装扩展；与本地服务通信（本地 HTTP 端口）；维护成本
- **适用**：A 方案表单变化时的兜底/人工介入模式

### 方案 C：半自动人工辅助（降级保底）
```
本地生成上传清单 → 打开光厂上传页 → 工具逐条填入剪贴板/自动聚焦，人工确认提交
```
- **优点**：零风控风险、实现最快
- **缺点**：效率低
- **适用**：A/B 受阻时的保底

**建议**：**A 为主 + C 兜底**（A 失败自动降级提示人工）；B 视 A 的稳定性后补。

## 四、技术架构

### 4.1 新表 `vjshi_upload_tasks`
```sql
CREATE TABLE IF NOT EXISTS vjshi_upload_tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  card_id INTEGER, gen_task_id INTEGER,   -- 来源词卡/生成任务
  video_file TEXT NOT NULL,               -- data/card_gen/videos/ 相对路径
  title TEXT DEFAULT '', keywords TEXT DEFAULT '',
  description TEXT DEFAULT '', category TEXT DEFAULT '',
  price INTEGER DEFAULT 0,                -- 售卖价格（分）
  is_ai INTEGER DEFAULT 1,                -- AI 作品标注
  status TEXT DEFAULT 'queued',           -- queued/uploading/filling/submitted/fail
  submit_ref TEXT DEFAULT '',             -- 作品编号/提交回执
  error TEXT DEFAULT '', fail_category TEXT DEFAULT '',
  creator_id INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now','localtime')),
  finished_at TEXT DEFAULT ''
);
```

### 4.2 后端 `backend/api/vjshi_upload.py`
| 组件 | 说明 |
|------|------|
| `_get_browser()` | Playwright `launch_persistent_context(data/vjshi_profile/)`（系统 Chrome 或 chromium） |
| `_ensure_login(page)` | 打开 vjshi.com 检测登录态；未登录 → 状态置 `need_login`，前端引导人工登录 |
| `_dump_form_config(page)` | **一次性实测工具**：登录后抓取上传页表单字段（name/id/class/placeholder）→ `data/vjshi_form_config.json` |
| `_upload_one(task)` | 按配置：上传文件 → 等进度 → 完善信息填表（逐字段映射）→ 提交 → 记录 submit_ref |
| `_build_meta(task)` | 标题/关键词/简介生成：词卡名+prompt 规则提取（LLM 可选路由） |
| worker | 全局锁串行 + 任务间隔（默认 45s 防风控）+ 孤儿接管 + 失败分类（login/form_changed/upload/review） |
| API | 单条/批量入队、任务列表、重试、删除、登录状态、表单配置查看 |

### 4.3 前端 `frontend/static/js/vjshi_upload_ui.js`
- 词卡生成历史/任务面板视频产物 → 「📤 投稿光厂」
- 投稿弹窗：自动生成的标题/关键词/简介/分类/价格（**全部可编辑**）+ AI 标注 → 确认入队
- 批量投稿：任务面板勾选 → 字段模板统一生成 → 逐条入队
- 上传任务面板：串行进度、状态徽章、失败原因、重试
- 登录状态条：`need_login` → 一键打开登录窗口（新标签人工登录）→ 检测成功

### 4.4 字段自动生成（标题规范对齐光厂）
- 光厂标题范式：`主体 + 内容 + 场景/风格`（如「4K非遗古法白酒酿造蒸煮工艺」）
- 生成规则：`{prompt 主体词} + {场景/动作} + {风格}`，长度 10-30 字，去广告词
- 关键词：主体/场景/风格/技术词，3-8 个
- 简介：`AI 生成视频素材：{prompt}（模型 {model} / {duration}s / {resolution}）`
- 分类：词卡 module/category 映射光厂分类（首期常见类目配置）
- LLM 增强（可选）：Ollama 路由生成创意标题（复用 role_parse 经验）

## 六、风险与边界

| 风险 | 对策 |
|------|------|
| 平台反自动化（风控/验证码） | 持久化 profile 保持登录；串行+间隔+节奏模拟；异常即停提示人工 |
| 表单结构变化 | 表单配置 JSON 化；`form_changed` 失败分类 → 重新实测 |
| 登录失效 | 状态检测 + 前端引导重新登录（人工一次） |
| AI 素材合规（原创/AI 标注） | 描述标注 AI 生成；上传前人工确认；价格/分类默认值可调 |
| 上传额度限制 | 前端展示额度；超限暂停并提示 |
| 账号安全 | 仅本机自动化，凭据存本地 profile，不上云 |
| 视频规格 | 即梦产物（mp4 4-30s）符合光厂 ≤15min 要求；分辨率 720p+ 达标 |

## 附：合规边界声明（v5.38.62 合规整改补充）

> 本方案涉及浏览器自动化批量投稿，平台协议边界与风控行为需明确约束，以下为整改后的红线与声明。

### 一、已实施的合规约束（v5.38.62）
1. **人工确认制**：服务重启后上传队列自动置为暂停，必须人工点「恢复」才继续执行；不自动续跑、不无人值守提交。
2. **限流熔断**：单条间隔 45s±15s；单日上限 30 条；**单小时上限 6 条**（新增）；连续失败 3 次自动暂停队列。
3. **批量上限**：单批入队 ≤20 条（新增）；灵感通道单次导入下载 ≤10 条（新增）。
4. **登录态**：仅复用人工手机验证码登录的持久化会话，代码不含任何自动登录/账号密码逻辑。
5. **灵感通道**（v5.38.62 新增）：移除浏览器自动化特征隐藏参数；搜索滚动轮次硬上限 8 轮；下载仅限用户显式勾选条目并二次确认，仅作个人灵感收藏参考。

### 二、平台协议风险红线（明示）
- 光厂（vjshi.com）协议含「素材上传频度」账号维度限制；连续高频自动化上传存在封号风险。
- 即梦（jimeng.jianying.com）公开发现页/搜索流内容版权归原作者；下载内容仅限个人灵感参考，禁止二次分发、商用或绕过平台授权。
- 本工具为**人工辅助工具**：入队、恢复、导入均由人工决策；任何「全自动无人值守投稿」用途均超出设计边界。

### 三、降级路径（方案 C 半自动，风险最低）
- 若平台风控收紧或账号受限：停用 Playwright 自动链路，改由工具生成「上传清单 JSON」→ 人工打开光厂上传页 → 工具提供剪贴板提示词辅助逐条粘贴填写 → 人工确认提交。
- 对应保留代码：_vjshi_inspect.py（表单结构实测）与 _build_meta（元数据生成）可独立于自动化链路使用。
