# 光厂AI素材合规自动化生产逻辑链路 — 标准流程文档 + 升级改造开发规划书

- **文档类型**：标准流程（SOP）+ 升级改造规划
- **归档日期**：2026-08-16
- **关联版本**：主项目 v5.38.64（光厂投稿链路已加固）、需求分析模块 v1.3
- **状态**：评审稿（供二喵确认后进入迭代排期）

---

## 一、链路总览

**一句话**：以"人工采集研判 → 合规辅助生产 → 人工触发投稿 → 销售回流迭代"为骨架，形成**低成本、低风控、可量产**的 AI 素材生产闭环。

```
①合规题材采集研判 → ②灵感多途径筛选 → ③人工词卡归档 → ④提示词质检评分排序
→ ⑤人工预览图验证筛选 → ⑥低积分seedance批量生成 → ⑦本地视频质检
→ ⑧人工触发合规自动填表投稿 → ⑨批量投稿审核 → ⑩上线精筛劣品剔除
→ ⑪销售数据回流迭代（回到①）
```

### 核心原则
1. **人工主导**：所有决策点（题材选择、词卡归档、预览验证、投稿触发、劣品剔除）由人工完成；系统仅做**数据运算与表单辅助**。
2. **合规零容忍**：无爬虫、无官网自动抓取、无后台无人值守运行、无账号池；仅操作自有账号、纯本地数据填充。
3. **风控优先**：投稿节奏（45s±15s 间隔、单时 6 条、单日 30 条）、连续失败熔断、重启人工确认恢复。
4. **数据闭环**：销售数据回流参与题材评分，形成"验证-迭代"飞轮。

## 二、合规红线总纲（全程适用）

| 红线 | 约束 | 对应系统设计 |
|------|------|-------------|
| R1 无自动抓取 | 禁止程序访问/抓取光厂官网任何资源（榜单/指数/预览/页面） | 需求分析模块零外网（静态扫描+运行时 selfcheck 双验证） |
| R2 仅人工上传数据 | 榜单/指数/关键词/销售数据一律人工下载、人工上传 | 需求分析模块数据入口仅 3 个（上传文件/公告录入/前端选择） |
| R3 无无人值守 | 无 cron、无定时自动运行、服务重启后队列置暂停待人工确认 | v5.38.62 人工确认制（_resume_orphaned 置 paused） |
| R4 仅人工触发 | Playwright 仅作人工触发的表单辅助工具；入队/恢复/提交均人工 | 入队需团队版权限+人工点击；resume 人工确认 |
| R5 仅自有账号 | 单 profile 单账号，复用真人手机验证码登录会话 | 持久化 profile，无脚本登录 |
| R6 纯本地数据 | 投稿信息 100% 来自本地词卡+本地 Ollama 生成 | _build_meta 本地生成，无站点回填 |
| R7 无规避检测 | 无 stealth、无指纹伪装、无 UA 篡改、无自动化特征隐藏 | v5.38.63 已清理全部规避意图代码 |
| R8 报错即停 | 提交被拒立即终止不自动重试；连续失败 3 次熔断 | fail_category 分类 + 人工重试 |

## 三、各环节标准流程（SOP）

### 环节① 合规题材数据人工采集研判
- **目标**：确定本期投产题材方向（四池划分）
- **输入**：官方《视频机会排行表》《视频热搜排行表》《视频关键词分析周报》（**人工从官网下载**）
- **操作步骤**：
  1. 人工登录光厂 → 素材/数据中心 → 手动下载排行 Excel（每周 1 次）
  2. 打开「需求分析」模块 → 上传快照（自动识别表型：机会榜双维/热搜榜单维/关键词分析）
  3. 运行分析 → 查看四池：主力投产池 / 内卷慎入池 / 蓝海观察池 / 滞销淘汰池
  4. 可视化概览（环形图/TOP10 柱状图）辅助决策；版本对比（新上榜/上升/下降/掉榜）观察趋势
  5. 人工在「研判工作台」对候选题材录入考察记录与风险记录
  6. 生成《题材开发规划书》（含合规风控章节）→ 确认本期题材清单
- **输出**：题材清单（主力池为主，蓝海池试探）
- **人工触发点**：下载、上传、运行分析、研判、规划书确认
- **系统模块**：需求分析（TED）模块（:8085）
- **合规边界**：R1/R2 —— 全程人工下载上传，模块零外网

### 环节② 灵感多途径筛选
- **目标**：为选定题材搜集创作灵感（画面参考/风格方向）
- **输入**：题材清单
- **操作步骤**：
  1. 即梦灵感搜索（关键词搜索 + 发现页浏览，可见 Chrome 窗口人工可观察）
  2. 即梦历史资产导入（本人账号作品，双通道：CLI 授权 + 网页登录）
  3. 多途径交叉：热搜上升榜词（七夕/医师节等时效题材）、机会榜双高题材
- **输出**：灵感候选集（元数据 + 预览图，仅个人灵感参考）
- **人工触发点**：搜索、滚动浏览、勾选导入（单次 ≤10 条，二次确认）
- **系统模块**：灵感通道（dreamina_inspiration，已合规整改）
- **合规边界**：R1 —— 仅人工浏览；下载仅限显式勾选；预览图仅供个人参考不二次分发

### 环节③ 人工词卡归档
- **目标**：把灵感/题材转化为可生产的词卡（提示词+参数+预览）
- **操作步骤**：
  1. 人工将筛选后的灵感导入词库（「导入并存词卡」或手动新建词卡）
  2. 填写提示词/风格/画幅/时长等字段，归档到对应维度分组
  3. 词卡打标（AI 标注、分类映射：人物/自然风光/商务/创意等）
- **输出**：词卡（含提示词与元数据）
- **人工触发点**：导入/新建/编辑/归档
- **系统模块**：词库系统（word_card + 灵感导入链路）
- **合规边界**：纯本地数据填充（R6）

### 环节④ 词卡提示词质检评分排序 ⭐（升级缺口 P0）
- **目标**：批量生成前对词卡提示词做质量评分与排序，淘汰低质词卡
- **当前状态**：**无 AI 质检评分功能**（仅有画质参数标签）→ 需升级
- **规划操作步骤**（升级后）：
  1. 一键质检：批量提取词卡提示词 → 本地 Ollama 规则+AI 双评
  2. 评分维度：完整性（主体/场景/风格/镜头）、一致性（提示词与分类/标签匹配）、合规性（无违禁词/广告词）、生产适配（时长/分辨率在模型上限内）
  3. 评分排序视图：高分优先、低分标记原因
  4. 人工复核低分卡（修改或剔除）
- **输出**：质检评分后的词卡队列（按分排序）
- **人工触发点**：运行质检、复核修改
- **系统模块**：词库 + Ollama（ollama_client 已有）

### 环节⑤ 人工预览图验证筛选
- **目标**：生成前人工确认画面方向，避免批量生成方向错误
- **操作步骤**：
  1. 查看词卡预览图（缩略图/查看原图/左右切换）
  2. 人工判断：画面是否符合题材预期、风格是否一致
  3. 不合格词卡退回修改或剔除
- **输出**：通过验证的词卡集
- **人工触发点**：预览查看、筛选
- **系统模块**：词库媒体/缩略图（已有）

### 环节⑥ 低积分 seedance 视频批量生成
- **目标**：以最低积分成本批量生产候选视频
- **操作步骤**：
  1. 提交前预检（batch-precheck：无内容/文件丢失/超长/手动图风险分类，高危卡一键排除）
  2. 批量入队（≤20 条/批，队列持久化）
  3. 生成引擎授权检查（即梦/LibTV 登录态）
  4. 任务面板监控进度（8s 轮询、完成后通知）
- **输出**：候选视频产物（data/card_gen/videos/）
- **人工触发点**：预检确认、批量入队、授权登录
- **系统模块**：card_gen 批量生成（已有 v5.34.x 全链路）
- **合规边界**：生成侧为平台官方 API 授权使用，非抓取（R1 不适用）；消耗真实积分 → 预检防浪费

### 环节⑦ 本地视频质检 ⭐（升级缺口 P1）
- **目标**：投稿前确保视频文件合规可用（时长/分辨率/完整性）
- **当前状态**：仅有文件存在性检查（file_missing）；无系统性视频质检
- **规划操作步骤**（升级后）：
  1. 投稿前自动质检清单：ffprobe 解析（时长 ≥5s、分辨率达标、编码 H.264、无黑帧/静音超限、文件大小合理）
  2. 质检报告随任务展示（通过/警告/不合格），不合格拦截上传
  3. 与投稿弹窗集成：预检通过才允许提交
- **输出**：质检通过的视频清单
- **人工触发点**：查看质检报告、处理不合格项
- **系统模块**：ffprobe（ffmpeg 已装）+ vjshi 投稿前检查

### 环节⑧ 人工触发浏览器合规自动填表投稿
- **目标**：将质检通过视频合规投递光厂（人工触发，自动填表）
- **操作步骤**：
  1. 人工打开上传队列面板（生成任务面板「📤 光厂队列」快捷入口）
  2. 单条/批量入队（人工点击确认投稿，弹窗内可编辑标题/关键词/简介/价格/AI标注）
  3. 可选「AI 优化简介」（本地 Ollama 10s 生成，已修复提速）
  4. worker 串行执行：打开上传页 → 选文件 → 等上传 → 自动填表（标题/关键词/简介/价格/AI标注/风格）→ 提交
  5. 提交结果确认（成功保留窗口 / 被拒落库 fail_category / 登录失效提示）
- **输出**：投稿任务（submitted 或 fail）
- **人工触发点**：入队、参数编辑、AI 简介、恢复队列
- **系统模块**：vjshi_upload（已加固：异常兜底/任务超时/卡死看门狗/单时6/日30/批20）
- **合规边界**：R3/R4/R5/R7/R8 全覆盖；45s±15s 节奏、连续失败熔断

### 环节⑨ 批量投稿审核 ⭐（升级缺口 P0）
- **目标**：跟踪光厂审核进度，掌握投稿状态全貌
- **当前状态**：任务终态仅 submitted/fail，无审核状态跟踪
- **规划操作步骤**（升级后）：
  1. 任务状态扩展：submitted → reviewing（人工录入"已进入审核"）→ online（已上架）/ rejected（被拒，记录原因）
  2. 批量审核面板：按状态分组（待审核/审核中/已上架/被拒），支持批量标记
  3. 被拒原因分类（标题不规范/关键词违规/版权存疑等）沉淀词卡质检规则
  4. 审核周期提醒（约 1 个工作日，超时提示复查）
- **输出**：审核状态台账
- **人工触发点**：人工查看光厂后台后录入状态（不自动查官网）
- **系统模块**：vjshi_upload_tasks 状态扩展 + 前端面板

### 环节⑩ 上线人工精筛劣品剔除 ⭐（升级缺口 P1）
- **目标**：上架后人工复盘，剔除表现差的作品，保持店铺质量
- **规划操作步骤**（升级后）：
  1. 上架作品台账（作品链接/题材/上传日期/审核结果）
  2. 人工按表现（销量/搜索曝光）标记剔除候选
  3. 剔除记录留痕（原因/日期），沉淀选题规则
- **输出**：上架管理台账 + 剔除记录
- **人工触发点**：人工浏览后台后录入
- **系统模块**：新增上架台账（前端表格 + 本地库）

### 环节⑪ 销售数据回流迭代
- **目标**：销售结果回流，验证题材方向，优化下一轮选题
- **操作步骤**：
  1. 人工导出光厂销售记录（自有账号后台）→ 上传需求分析模块（sales_record 表型自动识别）
  2. 合并分析：需求版本 + 销售版本按题材匹配 → 注入真实销量/收益信号（merged_orders）
  3. 已验证题材自动获得权重提升；无单题材降级
  4. 回到环节①：下一周期选题参考销售验证结果
- **输出**：带销售验证的新一轮题材池
- **人工触发点**：导出、上传、合并分析
- **系统模块**：需求分析模块（已支持 sales_record + compare）
- **合规边界**：R2 —— 销售数据人工导出上传

## 六、数据回流与迭代机制

```
销售记录（人工导出）→ 需求分析模块 sales_record → 合并分析注入销量信号
→ 题材池重排（已验证题材提升）→ 下一轮 ① 选题 → ②③④⑤⑥⑦⑧⑨⑩ → 销售再回流
```
- 回流周期：按周（官方周报频率）
- 验证信号：merged_orders（真实出单数）、收益金额
- 决策规则（人工参考）：主力池 + 已出单 ≥ 2 笔 → 加量投产；主力池 + 零出单 3 周 → 降级观察

## 七、合规检查点清单（每轮执行前过一遍）

- [ ] 数据来源：所有外部数据均为人工下载/导出后上传（无程序拉取）
- [ ] 无 cron/定时任务新增；重启后队列处于暂停态
- [ ] 投稿仅人工触发；无无人值守批量提交
- [ ] 仅操作自有账号（单 profile）；无账号池
- [ ] 投稿信息来自本地（词卡/Ollama）；无站点回填
- [ ] 无 stealth/指纹/UA 伪装残留（需求分析模块 selfcheck 通过）
- [ ] 节奏合规：45s±15s、单时 ≤6、单日 ≤30、失败熔断
- [ ] 报错即停：被拒任务不自动重试

## 八、成本与量产策略

- **成本控制**：低积分模型优先（seedance 档位按模型上限降级）；批量前预检防额度浪费；单卡先预览验证再生成
- **量产节奏**：每周 1 轮（周一采集研判 → 周二~四生成 → 周五投稿 → 下周回流复盘）
- **规模目标**：单轮主力池 10-20 题材 × 每题材 2-3 条候选 = 20-60 条投稿/周（受单日 30 条上限约束，分批提交）
