## 九、项目管理插件 v1.0.3 — 4项UI修复

### #1 编辑成员档案窗口不居中
**根因**: `_editMember()` 中 `ov.style.alignItems='flex-start'` 覆盖了 `.pk-modal-overlay` 的 `align-items:center`
**修复**: 删除该行，恢复 CSS 原有居中效果

### #2 权限设置配色看不清
**根因**: JS内联 `background:var(--bg-secondary,#f8fafc)` —深色模式下 `--bg-secondary` 不存在，回退到浅灰白
**修复**: 移除内联样式，改为 CSS 类 `.pk-perm-wrap`，深色模式显式 `background:#0f172a;border:1px solid #334155`

### #3 权限设置复选框与文字不对齐
**根因**: flex `align-items:center` 对 checkbox 效果不一致
**修复**: 改用自然行内布局 — checkbox `vertical-align:text-bottom;line-height:16px;width:16px;height:16px` + `margin-right:8px`，与文字同基线

### #4 编辑成员档案 / 成员详情 窗口双栏统一
