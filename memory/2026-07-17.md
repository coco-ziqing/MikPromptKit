## 5. 批量改文件的血泪教训（Windows 环境）
- **PowerShell `-replace` / Set-Content 会破坏 UTF-8 中文/emoji 编码** → 禁用。
- **正则批量替换吃引号**曾一次损坏 18 个 JS 文件语法 → 禁用花哨正则。
- **可靠方案：Node.js 脚本 + `replaceAll` 精确字符串对**（fs.readFileSync/writeFileSync 'utf8'），改完必跑 `node --check` 全量验证。
- Python 脚本长时间运行可能被超时 kill 导致文件写一半损坏 → 大批量任务拆小。
- git checkout 回滚会连 P0 一起退掉——重做前先确认哪些文件是干净基线。
