【需求名称】导航词库菜单新增「词卡采集」功能

【需求背景】
在 MikPromptKit 提示词工作站（Python FastAPI + SQLite FTS5 + Bootstrap 5 SPA，局域网 WebUI）的导航「词库」菜单中，新增「词卡采集」入口与功能，打通"外部灵感内容 → 本地词卡"的采集归档全流程。

【需求说明（用户原话要点）】
1. 采集源：AI 生成平台、公开灵感图库/视频库，规避违规风险。
2. 交互方式：用户通过输入/粘贴访问地址（URL），应用进行浏览器自动化操作访问页面。
3. 采集对象：对访问页中的信息进行自主识别——识别生成图片/视频及其对应的提示词信息、生成模型/参数等信息。
4. 入库去向：
   a) 采集后首先建立「预采集库」，对信息进行基础整理和存储；
   b) 然后通过"自主识别 + 手动"两种方式结合进行分组和归档；
   c) 最终建立相应的词卡。
5. 边界约束：
   a) 设计浏览器自动化，不涉及登录态（不登录、不填账号）；
   b) 需要联网；
   c) 尽量规避违规操作（仅采集公开内容、尊重平台规则、不绕过风控、不批量抓取他人私密内容、遵守 robots/合规边界）。
6. 阶段规划：
   a) 第一阶段：手动基础链路功能实现，打通「采集 → 整理 → 分组归档 → 建词卡」全流程；
   b) 第二阶段：规划小批量自动化采集方案（本阶段仅做规划，不实现）。

【技术栈约束】
- Python 3.14 + FastAPI 0.115 + Uvicorn（0.0.0.0:8080）
- SQLite WAL 模式 + FTS5 全文索引
- Bootstrap 5 + Vanilla JS SPA
- 浏览器自动化：已有 Playwright CDP 方案沉淀（参考即梦历史资产网页通道经验：独立 Chrome profile、port=0、CDP 读真实响应、滚动容器定位、合规边界）
- 纯局域网工具，不暴露公网

【合规红线（沿用项目既有审计结论）】
- 无验证码绕过、无账号池、无代理、无风控对抗
- 滚动采集轮数受限、预览数量受限、单次导入数量受限（后端拦截 + 前端确认）
- 服务重启后自动化任务默认暂停，待人工确认恢复
