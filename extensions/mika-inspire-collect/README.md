# 咪卡灵感收藏助手（Chrome MV3 扩展）

把浏览器中浏览的灵感页面**一键回传**至咪卡词库（MikPromptKit）的 URL 收藏库，是「灵感站点导航 → 多标签浏览 → URL 归集 → 收藏库筛选 → 批量采集」链路的浏览器端桥梁。

## 功能

- **📥 收藏当前页**：点击扩展图标 → 一键把当前激活标签页地址回传至应用「待处理池」，应用自动抓取标题/摘要/首图
- **📚 批量收藏全部标签**：读取浏览器当前全部标签（自动过滤 chrome://、about:、扩展页等非网页），**勾选确认后**统一回传入库（人工确认制，不自动批量入库）
- **🔗 手动粘贴兜底**：应用内「URL收藏库」支持多行粘贴入库（与扩展同一确认流程）

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启 **「开发者模式」**
3. 点击 **「加载已解压的扩展程序」**，选择本目录：`extensions/mika-inspire-collect`
4. 浏览器工具栏出现 📥 图标即安装完成

> 局域网工具，无需上架商店；开发者模式加载即可永久使用（重启浏览器仍生效）。

## 使用前提

- 咪卡词库服务已启动并监听 `127.0.0.1:8080`（扩展只连本机回环地址，不发外网）
- 打开扩展弹窗时会自动检测服务连接状态（✅/❌）

## 权限说明（最小化）

| 权限 | 用途 |
|---|---|
| `tabs` | 读取标签页 URL（仅 http/https 公开地址） |
| `storage` | 保留后续设置项（当前未使用） |
| `host_permissions` | 仅 `127.0.0.1:8080` / `localhost:8080`（本地服务回传） |

**合规声明**：不读取 Cookie、密码、表单、历史记录等任何隐私数据；不自动批量入库（必须用户勾选确认）；回传内容仅限本机咪卡服务，数据不上云、不发公网。
