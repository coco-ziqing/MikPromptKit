# TED 模块 — 数据准备指引（人工下载 → 人工整理 → 人工上传）

> **合规红线提醒**：本模块**不自动访问**光厂官网。以下数据获取动作**全部由人工完成**：
> 人工打开官网 → 人工浏览/下载 → 人工检查整理 → 人工上传到模块。模块侧没有任何自动获取逻辑。

## 一、官方数据源（人工下载）

光厂（vjshi.com）素材中心提供以下官方公开排行数据，**人工**下载即可（实测 2026-08-16 版本）：

| 表名 | 官方结构 | 用途 |
|------|---------|------|
| **视频_机会排行.xlsx** | 1 个 sheet「机会排行」：`排名 / 搜索词 / 需求指数 / 机会指数`（约 510 行） | 双维评分 → 四类题材池（主分析表） |
| **视频_热搜排行.xlsx** | 2 个 sheet：「热搜榜」「上升榜」，各 `排名 / 搜索词 / 作品数`（各约 100 行） | 单维作品数热度 → 热度导向分池（补充参考表） |

下载渠道：光厂官网登录后 → 素材/数据中心 → 排行页面 → **手动点击下载 Excel**。
（具体菜单位置以官网当前版本为准，人工浏览确认。）

## 二、官方表结构说明（模块已自动适配，无需整理）

官方表格可直接上传，模块自动处理：
- **R1 元信息行**（榜单时间/下载时间）→ 自动跳过，定位 R2 表头行
- **多 sheet**（热搜榜/上升榜）→ 自动合并导入，版本记录标注 sheets
- **数值带尾随空格**（如 `'77.7 '`）→ 自动清理
- **列名自动识别**：搜索词/关键词/题材、需求指数/热度、机会指数、作品数（中英文均可）

## 三、上传步骤

1. 启动模块：双击 `ted_module/start.bat` → 打开 http://127.0.0.1:8085
2. 进入「上传快照」→ 选择官方 Excel → 填写版本名（如 `2026-08-16 官方机会排行`）→ 上传
3. 版本记录标注**表型识别**（视频机会排行表 / 视频热搜排行表）与 sheets
4. 进入「数据分析」→ 选择版本 → 运行分析 → 查看四类题材池

## 四、分析语义说明

| 表 | 评分维度 | 池划分 |
|----|---------|--------|
| 机会排行表 | 需求指数 + 机会指数（百分位归一化 0-100） | 主力投产池（双高）/ 内卷慎入池（需高机低）/ 蓝海观察池（需低机高）/ 滞销淘汰池（双低） |
| 热搜排行表 | 作品数（单维，百分位归一化作热度分） | 高热度=主力投产候选 / 中热度=蓝海观察 / 低热度=滞销淘汰 |

> 说明：热搜表「作品数」为该搜索词下的作品总量，反映市场热度与供给规模；作品数多=词热（主力候选），但竞争也可能激烈，投产前建议在工作台完成人工研判（结合机会表数据交叉验证）。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 官方表有多个 sheet | 自动合并导入（如热搜榜+上升榜），无需拆分 |
| 表头在第 2 行（前面有榜单时间） | 自动定位表头行，无需删除元信息行 |
| 两个表都分析 | **分开上传**为两个版本，各自运行分析；研判时交叉参考 |
| 想用通用模板 | 第一行表头：`题材 / 需求指数 / 机会指数 / 销量 / 销售额 / 排名`，仅题材+需求指数必填 |
