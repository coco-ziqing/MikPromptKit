# TED 模块 — 数据准备指引（人工下载 → 人工整理 → 人工上传）

> **合规红线提醒**：本模块**不自动访问**光厂官网。以下数据获取动作**全部由人工完成**：
> 人工打开官网 → 人工浏览/下载 → 人工检查整理 → 人工上传到模块。模块侧没有任何自动获取逻辑。

## 一、官方数据源（人工下载）

光厂（vjshi.com）供稿人后台/素材中心提供以下官方公开排行数据，**人工**下载即可：

| 表名 | 内容 | 用途 |
|------|------|------|
| **视频机会排行表** | 各题材/关键词的 需求指数 + 机会指数（+排名） | 双维评分 → 四类题材池（主分析表） |
| **热搜关键词排行表** | 热搜关键词 + 热度/热搜指数（+排名） | 单维热度 → 热度导向分池（补充参考表） |

下载渠道：光厂官网登录后 → 素材/数据中心 → 排行/机会页面 → **手动点击下载 Excel**。
（具体菜单位置以官网当前版本为准，人工浏览确认。）

## 二、整理要求（人工检查）

模块支持**直接导入官方原表**（自动识别表型与列名），也可整理为统一模板：

### 2.1 直接导入官方原表（推荐）
- 表头保留官方列名，模块自动识别：
  - 含「机会指数/需求指数」列 → 识别为**视频机会排行表**（双维分析）
  - 含「热搜/热度」列 → 识别为**热搜关键词排行表**（单维热度分析）
- 删除无数据的空行、说明行（如有「数据来源/更新时间」等说明行请删掉或移到表下方）

### 2.2 统一模板（手动整理时使用）
第一行表头，中英文列名均可：

| 题材 | 需求指数 | 机会指数 | 销量 | 销售额 | 排名 |
|------|---------|---------|------|--------|------|
| 城市夜景 | 95 | 80 | 500 | 30000 | 1 |
| 国潮 | 88 | 30 | 300 | 15000 | 2 |

- 「题材/需求指数」为必填列；其余缺列自动置 0
- 保存为 `.xlsx` 或 `.csv`（CSV 支持 UTF-8/GBK）

## 三、上传步骤

1. 启动模块：双击 `ted_module/start.bat` → 打开 http://127.0.0.1:8085
2. 进入「上传快照」页 → 选择文件 → 填写版本名（如 `2026-08-W33 官方机会表`）→ 上传
3. 版本记录中会标注**表型识别**结果（视频机会排行表/热搜关键词排行表）
4. 进入「数据分析」→ 选择版本 → 运行分析 → 查看四池划分

## 四、常见问题

| 问题 | 处理 |
|------|------|
| 表头是英文/官方特殊列名 | 模块自动映射（关键词/keyword、热度/heat、机会/opportunity 等），无需修改 |
| 表里有合并单元格/多行表头 | 人工整理为单行表头后上传 |
| 两个表都要分析 | **分开上传**为两个版本（机会表双维分析；热搜表单维热度分析），各自运行分析 |
| 上传报「未解析到有效数据行」 | 检查第一行是否为表头、题材列是否有值 |
